INTRODUCTION
------------
This project contains three websites created using HTML and CSS.
The main purpose is to learn webpage design, forms, navigation,
styling, and responsive web development.

PROJECT 1: PERSONAL PORTFOLIO WEBSITE
=====================================

Description:
This website displays personal information, educational
qualifications, technical skills, hobbies, projects,
achievements, resume, and contact details.

Features:
- Navigation menu
- Profile and education details
- Technical skills and hobbies
- Projects and achievements
- Resume and contact information
- CSS animations and hover effects
- Responsive webpage design

Usage:
1. Open the Personal Portfolio HTML file.
2. Browse the sections using the navigation menu.
3. View the profile, education, skills, and projects.
4. Use the resume and contact links.

Output:
Displays a personal portfolio webpage with a blue header,
navigation menu, white content sections, and footer.

PROJECT 2: USER REGISTRATION AND LOGIN
======================================

Description:
This website contains forms for registration, login,
password recovery, and profile setup.

Features:
- Registration form
- Login form
- Password recovery form
- Profile setup form
- Email and password fields
- HTML form validation
- Accessible form labels
- CSS focus and hover effects

Usage:
1. Open the User Registration and Login HTML file.
2. Enter details in the registration form.
3. Enter email and password in the login form.
4. Use the password recovery form.
5. Enter profile information in the profile setup form.

Output:
Displays four forms with styled input fields, buttons,
and a light blue background.

Note:
Actual authentication and password recovery require a
backend or suitable JavaScript.

PROJECT 3: RESTAURANT AND CAFE WEBSITE
======================================

Description:
This website presents restaurant information, food menus,
chef profiles, customer testimonials, opening hours,
location details, and a table reservation form.

Features:
- Restaurant welcome section
- Food menu with prices
- Chef profiles
- Restaurant ambience
- Customer testimonials
- Opening hours
- Contact information
- Table reservation form
- Responsive layout and hover effects

Usage:
1. Open the Restaurant and Cafe HTML file.
2. Browse the food menu and chef profiles.
3. Read customer reviews.
4. Check the opening hours and contact details.
5. Enter details in the table reservation form.

Output:
Displays a restaurant webpage with brown and cream colors,
menu cards, information sections, and a reservation form.

Note:
The reservation form does not save or send bookings
without a backend or suitable JavaScript.

TECHNOLOGIES USED
=================

1. HTML5
   Used to create the structure of the webpages.

2. CSS3
   Used to style the webpages, colors, forms, buttons,
   layouts, hover effects, animations, and responsiveness.

HOW TO RUN THE PROJECTS
=======================

1. Save the HTML files in the project folder.
2. Open the folder in Visual Studio Code.
3. Right-click the required HTML file.
4. Select "Open with Live Server".
5. The website opens in your browser.

Alternatively, double-click an HTML file to open it
directly in a web browser.
